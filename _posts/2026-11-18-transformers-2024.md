* [2024] [DeepSeek-V3](https://arxiv.org/abs/2412.19437): 671B-A37B. 14.8T tokens. MLA. GRPO. FP8 training (many details about quantization). MTP objective. Node-limited routing. No token dropping. Aux-loss-free load balancing (also sequence-wise balance loss). ZeRO-1+PP16+EP64 across 8 nodes. DualPipe. Activation checkpointing for RMSNorm and MLA up-projections. Param EMA in CPU.  
* [2024] [OLMo 2](https://arxiv.org/abs/2501.00656): 13B. 5.6T tokens. RMSNorm. QK-Norm. Z-loss. No weight decay on embeddings. SwiGLU. RoPE. Spike score similar to [this](https://x.com/karpathy/status/1812917107379872145). AdamW with cosine decay (epsilon 1e-5 -> 1e-8).  
* [2024] [Qwen 2.5](https://arxiv.org/abs/2412.15115): 72B. 18T tokens. GQA. SwiGLU. RoPE. QKV bias. RMSNorm.  
* [2024] [Gemma 2](https://arxiv.org/abs/2408.00118): 27B. 2B and 9B via KD. 13T tokens. Interleaved local-global attention. GQA. RoPE. GeGLU. Logit soft-capping for attention and final layer. RMSNorm both pre and post.  
* [2024] [Llama 3](https://arxiv.org/abs/2407.21783): 405B. 15T tokens. GQA. Attention mask. RoPE freq increased to 500K. AdamW with cosine decay to 1%. Batch size scaling.  
* [2024] [Qwen 2](https://arxiv.org/abs/2407.10671): 72B dense and 57B-A14B MoE. 7T tokens (tried 12T but didn't make a difference). Same tokenizer as Qwen 1. GQA. Dual Chunk Attention with YARN for long context. RoPE (10k->1000K). QKV bias. RMSNorm. SwiGLU.  AdamW with cosine decay.  
* [2024] [Yi](https://arxiv.org/abs/2403.04652): 34B. 3.1T tokens. GQA. SwiGLU. RoPE ABF. AdamW with constant LR. ZeRO-1+TP+PP.  
* [2024] [YuLan](https://arxiv.org/abs/2406.19853): 12B. 1.7T tokens. Added Chinese to the llama tokenizer. RoPE. SwiGLU. RMSNorm. GPT-NeoX training framework. Curriculum learning. AdamW with cosine decay. ZeRO+TP on 96 A100s.  
* [2024] [DeepSeek-V2](https://arxiv.org/abs/2405.04434): 236B-A21B. 8.1T tokens. MLA (and decoupled RoPE for compatibility). GRPO. Device-Limited routing. Aux loss: expert level + device level + comms balance. AdamW with step decay. Batch size scheduling. Modified YaRN.  
* [2024] [GLM-4](https://arxiv.org/abs/2406.12793): 9B. 10T tokens. RMSNorm. SwiGLU. 2D RoPE. No Bias Except QKV. GQA. LongAlign for context extension.  
* [2024] [Mixtral](https://arxiv.org/abs/2401.04088): 47B-A13B. Similar to 7B dense.  
* [2024] [Gemma](https://arxiv.org/abs/2403.08295): 7B. 6T tokens. Same tokenizer as PaLM. MHA for bigger and MQA for smaller. RoPE. Tied embeddings. GeGLU. RMSNorm.  
* [2024] [OLMo](https://arxiv.org/abs/2402.00838): 7B. 2.46T tokens. GPT-NeoX - increase vocab size to multiple of 128. Weight tying only in smaller. Intermediate checkpoints. Non-parametric LayerNorm. No biases. SwiGLU. RoPE. ZeRO. Constant batch size. Scaled init. AdamW with linear decay (epsilon 1e-5, not 1e-8).  
* [2024] [DeepSeek](https://arxiv.org/abs/2401.02954): 67B. 2T tokens. Huggingface tokenizer. RMSNorm. SwiGLU. GQA. RoPE. Unlike most GQA models, expanded depth over width. AdamW with multi-step decay (found to be similar to cosine). HAI-LLM. ZeRO-1+TP+SP+PP. Scaling laws for LR/batch size based on FLOPs/token instead of params as measure of scale.
