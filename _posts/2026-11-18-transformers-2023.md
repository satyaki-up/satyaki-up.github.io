* [2023] [LLM360](https://arxiv.org/abs/2312.06550): 7B. 1.4T tokens. Intermediate checkpoints (and optimizer states). Partial RoPE (25% and inverse freq FP32). Similar to llama. AdamW with cosine decay. Trained using pytorch lightning.  
* [2023] [Mistral](https://arxiv.org/abs/2310.06825): 7B. GQA+SWA.  
* [2023] [Falcon](https://arxiv.org/abs/2311.16867): 180B. 3.5T tokens, mostly from RefinedWeb - many details about data curation. 4096 A100s, directly from S3 and no distributed file system. TP8+PP8+DP64. GQA. RoPE. Parallel attention and MLP blocks. No biases in linear layers. Z-loss. Tied embeddings. AdamW with cosine decay. No dropout. Batch size warm-up (steady for GPUs and drastic for TPUs).  
* [2023] [Qwen](https://arxiv.org/abs/2309.16609): 14B. 3T tokens. tiktoken. Split numbers into digits. FP32 RoPE. Untied embeddings. Biases only in QKV layer. RMSNorm. SwiGLU. Reduced MLP dim from 4x to 8/3x. AdamW with cosine decay. NTK-aware interpolation instead of position interpolation for increased context length. LogN-Scaling to reduce attention entropy and variable-window attention.  
* [2023] [Skywork](https://arxiv.org/abs/2310.19341): 13B. 3.2T tokens. RoPE. RMSNorm. SwiGLU. Megatron-LM on 512 A800s. DP256+PP2+ZeRO-1.  
* [2023] [Baichuan 2](https://arxiv.org/abs/2309.10305): 13B. 2.6T tokens. Intermediate checkpoints released. RoPE in 7B and ALiBi in 13B. Split numbers into digits. SwiGLU. RMSNorm. AdamW with cosine decay. NormHead. Max-z loss. ZeRO+TP. Tensor splitting via Tsplit.  
* [2023] [MPT-7B](https://www.databricks.com/blog/mpt-7b): 7B. 1T tokens. GPT-NeoX tokenizer but resize vocab size - multiple of 128 and leave tokens available. Over 10 days on 440 A100s. Only FSDP. ALiBi. Lion optimizer.  
* [2023] [Llama 2](https://arxiv.org/abs/2307.09288): 70B. 2T tokens. GQA. RMSNorm. AdamW with cosine decay. A100s. RoCE scaled as well as IB up to 2000 GPUs.  
* [2023] [Pythia](https://arxiv.org/abs/2304.01373): 12B. Multiple checkpoints. Custom tokenizer trained on the Pile. 300B tokens. Partial RoPE (25%). Parallel attention and MLP. Untied embeddings. Trained using the library GPT-NeoX. ZeRO and TP. Higher batch sizes 4-8x.  
* [2023] [PaLM 2](https://arxiv.org/abs/2305.10403): 340B. 3.4T tokens. Chinchilla optimal. Canary tokens.  
* [2023] [Llama-1](https://arxiv.org/abs/2302.13971): 65B. 1.4T tokens. Modified SentencePiece. SwiGLU. RoPE. AdamW with cosine decay. Efficient attention from xformers. Activation checkpointing. 380 tokens/sec/GPU on 2048 A100s over 21 days.
